PHILAB 개인정보처리방침

시행일: 2026년 11월 19일

1. 목적

PHILAB은 영상 편집팀 내부 업무용 도구로, 운영자 본인의 Google 계정으로 로그인해 업무용 Google 스프레드시트를 읽는 데만 사용합니다.

2. 이용하는 정보

사용자가 허용한 범위 안에서 Google 스프레드시트의 내용을 읽습니다. 로그인 유지를 위한 인증 토큰은 운영자 PC에만 저장됩니다.

3. 이용하지 않는 것

Google 사용자 데이터를 판매하거나 광고에 쓰지 않으며, 제3자에게 제공하거나 외부 서버로 전송하지 않습니다.

4. 보관과 삭제

읽은 내용은 업무 확인에 필요한 동안만 운영자 PC에 보관합니다. 사용자는 언제든 Google 계정 설정의 '타사 앱 및 서비스'에서 접근 권한을 해제할 수 있습니다.

5. Google API 서비스 사용자 데이터 정책 준수

PHILAB이 Google API로 받은 정보의 사용은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
